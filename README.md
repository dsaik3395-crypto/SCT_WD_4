# SCT_WD_4 - To-Do Web App

This is my **Task 04** project for the **SkillCraft Technology Web Development Internship**.

##  Project Description
A basic To-Do Web Application that allows users to:
- Add and maintain tasks
- Organize items in lists
- Mark tasks as Completed
- Edit tasks
- Set Date & Time for tasks

##  Features
- Add new tasks
- Edit existing tasks
- Delete tasks
- Mark tasks as Completed / Incomplete
- Set Due Date and Time
- Organize tasks
- Data saved using Local Storage
- Responsive design

##  Technologies Used
- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Local Storage

##  How to Run
1. Clone the repository
2. Open `index.html` in your browser
3. Or use Live Server in VS Code
